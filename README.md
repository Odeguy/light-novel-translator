# Light Novel Translator
  
Access at https://light-novel-translator-jih4.onrender.com  
Depolyed with Render

## How to Use

1.  Select 'New Series' Button and add a name as well as a thumbnail.  <img width="2880" height="1658" alt="image" src="https://github.com/user-attachments/assets/6a1e5eaa-6d80-40b1-b8b4-65615d24dc5e" />
2.  To add on a new chapter, select 'Translate New Chapter'. Choose a file, model, and language. If you don't have the respective api key, select 'Get API Key' to go to the website for it. If you selected an AI model, you can add extra details for clarity & consistency. When you have filled out all necessary parameters, select 'Submit'.<img width="2880" height="1658" alt="image" src="https://github.com/user-attachments/assets/014bd09a-43da-4b33-bb40-71582f39f5fd" />  
3.  To delete chapters, toggle delete chapters mode with the butt in the bottom left. Use the button to the left to delete the series. <img width="2880" height="1658" alt="image" src="https://github.com/user-attachments/assets/a43ad385-09d3-4c95-b310-c1aded188dde" />
